# OTPKeep

免费、跨五端（Windows、macOS、Linux、iOS、Android）的两步验证（TOTP / HOTP）验证器。

[English](README.md)

> **状态：** 早期开发中，尚无可用的版本。

- **随手取码：** 菜单栏 / 托盘、全局快捷键、搜索面板、命令行
- **备注与标签：** 按名称、服务商、账号、标签、备注搜索，支持中文拼音与首字母
- **Google Authenticator：** 通过转移二维码双向迁移
- **局域网同步：** 设备配对后端到端加密同步，只在同一局域网、在你打开的限时窗口内一对一进行；每次同步需一次性同步码并在另一台设备上确认。不使用任何服务器
- **隐私优先：** 本地数据整体加密，密钥存放在系统密钥库；无遥测
